# Auto Service AI

Initial MVP for an AI-assisted customer retention and service reminder platform for automobile/tyre retail shops.

## Initial flow

Customer scans QR -> enters name, mobile number and vehicle number -> transaction/service is recorded -> system calculates the next expected oil-change date -> reminder can be sent.

## Stack

- Java 21
- Spring Boot
- Gradle
- PostgreSQL
- Spring Data JPA
- Flyway
- Validation

## First milestone

Get the application running locally, then build the Customer API.
